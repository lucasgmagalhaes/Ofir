# E0305: unused `Result`

A call returns a `Result` and its value is dropped: the error, if there
is one, would be lost without a trace. A `Result` must be handled, or
ignored on purpose.

## Example

```ofir
fn parse(s: str) Result<int, str> {
    if s == "1" {
        return Result.Ok(1)
    }
    return Result.Err("not a number")
}

fn main() {
    parse("x")
}
```

## Fix

Handle the error, or ignore it explicitly with `let _ = ...`:

```ofir
fn parse(s: str) Result<int, str> {
    if s == "1" {
        return Result.Ok(1)
    }
    return Result.Err("not a number")
}

fn main() {
    match parse("x") {
        Result.Ok(n) => println("{n}")
        Result.Err(e) => println("error: {e}")
    }
}
```
