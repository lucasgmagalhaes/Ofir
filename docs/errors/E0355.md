# E0355: `dyn` value stored by value

The size of a `dyn I` value depends on the type it holds, so it is not
known at compile time. It can be borrowed (`&dyn I`) or boxed
(`Box<dyn I>`), but not stored directly in a field, a variable or a
list.

## Example

```ofir
interface Shape {
    fn area(self) int
}

struct Holder {
    shape: dyn Shape
}

fn main() {
}
```

## Fix

```ofir
interface Shape {
    fn area(self) int
}

struct Holder {
    shape: Box<dyn Shape>
}

fn main() {
}
```
