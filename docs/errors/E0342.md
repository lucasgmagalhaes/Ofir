# E0342: the fields of these keys have different types

An indexed access type `T[K]` with several keys is the type of all their
fields, so the fields must have the same type (spec 16.3).

## Example

```ofir
struct Point {
    x: float
    y: float
    id: int
}

type Value = Point[keyof Point]

fn show(v: Value) {
}

fn main() {
}
```

## Fix

Leave out the keys of the other fields:

```ofir
struct Point {
    x: float
    y: float
    id: int
}

type Value = Point[keyof Point - .id]

fn show(v: Value) {
}

fn main() {
}
```
