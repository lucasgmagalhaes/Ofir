# E0005: integer literal too large

An integer literal does not fit in 64 bits. Literals larger than the
largest `u64` cannot be written.

## Example

```ofir
fn main() {
    const n = 99999999999999999999
    println("{n}")
}
```

## Fix

```ofir
fn main() {
    const n: u64 = 9999999999999999999
    println("{n}")
}
```
