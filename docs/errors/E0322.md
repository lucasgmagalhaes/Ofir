# E0322: type cannot be cloned

`.clone()` is called on a value with a part that has a `drop` method
but no `clone` method: a resource such as a file handle cannot be
duplicated field by field.

## Example

```ofir
struct Handle {
    fd: int

    fn drop(mut self) {
    }
}

fn main() {
    const h = Handle{fd: 1}
    const dup = h.clone()
    println("{dup.fd}")
}
```

## Fix

Declare a `clone` method that says how to duplicate it, or share the one value:

```ofir
struct Handle {
    fd: int

    fn drop(mut self) {
    }

    fn clone(self) Handle {
        return Handle{fd: self.fd}
    }
}

fn main() {
    const h = Handle{fd: 1}
    const dup = h.clone()
    println("{dup.fd}")
}
```
