# E0806: `@lang` declaration with the wrong layout

A standard library type marked `@lang` does not declare the fields the
compiler expects for that built-in type. The compiler generates code
that reads these fields directly, so their order and types are fixed:
`str` is `ptr: *u8`, `len: int`, `cap: int`; `List<T>` is
`ptr: *mut T`, `len: int`, `cap: int`; a numeric type declares no
fields. The error is seen only when changing `std`.

## Example

```text
// std/core/str.of
@lang("str")
struct str {            // error[E0806]: `@lang("str")` must declare `ptr: *u8`, `len: int`, `cap: int`
    ptr: *u8
    len: int
}
```

## Fix

```text
// std/core/str.of
@lang("str")
struct str {
    ptr: *u8
    len: int
    cap: int
}
```
