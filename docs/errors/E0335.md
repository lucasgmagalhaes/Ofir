# E0335: asserted interface not satisfied

A type asserts an interface (`struct Circle: Shape`) but lacks one of
its methods, or has one with a different signature. The assertion is
checked where the type is declared.

## Example

```ofir
interface Shape {
    fn area(self) float
}

struct Circle: Shape {
    r: float
}

fn main() {
}
```

## Fix

Add the missing method:

```ofir
interface Shape {
    fn area(self) float
}

struct Circle: Shape {
    r: float

    fn area(self) float {
        return 3.14 * self.r * self.r
    }
}

fn main() {
}
```
