# E0602: move out of a borrowed place

A value is moved out of something the function only borrows: a field
of a parameter that is not `move`, an element of a list, or the target
of a reference. Taking it would leave the owner with a hole.

## Example

```ofir
struct User {
    name: str
}

fn nameOf(u: User) str {
    return u.name
}

fn main() {
    println(nameOf(User{name: "ana"}))
}
```

## Fix

Take the parameter by `move`, or clone the part:

```ofir
struct User {
    name: str
}

fn nameOf(u: User) str {
    return u.name.clone()
}

fn main() {
    println(nameOf(User{name: "ana"}))
}
```
