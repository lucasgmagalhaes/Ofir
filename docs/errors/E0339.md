# E0339: method not callable through `dyn`

A method of an interface with a default body may be generic, take
`self` by value or mention `Self`; the interface is still usable as
`dyn I`, but that method cannot be called through it.

## Example

```ofir
interface Shape {
    fn area(self) int

    fn pick<T>(self, x: move T) T {
        return x
    }
}

fn scale(s: &dyn Shape) {
    s.pick(2)
}

fn main() {
}
```

## Fix

Call it on the concrete type, or through a type parameter:

```ofir
interface Shape {
    fn area(self) int

    fn pick<T>(self, x: move T) T {
        return x
    }
}

fn scale<S: Shape>(s: &S) {
    let _n = s.pick(2)
}

fn main() {
}
```
