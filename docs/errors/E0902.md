# E0902: toolchain failed

The program was checked, but building the executable failed: the
generated `.ll` file could not be written, clang could not be run or
reported an error, or the runtime library `libofir_rt.a` was not
found. `ofir version` shows the clang in use; `$OFIR_CLANG` and
`$OFIR_RUNTIME` choose another (`docs/design/toolchain.md`).

## Example

```text
$ ofir build hello.of
error[E0902]: cannot run `clang`
```

## Fix

Install clang 17 or later, or point the compiler at it:

```text
$ OFIR_CLANG=/usr/lib/llvm-17/bin/clang ofir build hello.of
```
