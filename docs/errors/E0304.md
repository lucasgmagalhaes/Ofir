# E0304: cannot assign twice to immutable variable

A variable declared with `const` is bound once. Assigning to it again is
an error: declare it with `let` when it has to change.

## Example

```ofir
fn main() {
    const n = 1
    n = 2
    println("{n}")
}
```

## Fix

```ofir
fn main() {
    let n = 1
    n = 2
    println("{n}")
}
```
