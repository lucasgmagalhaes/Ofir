# E0334: bound on a non-parameter

A `where` clause puts a bound on something that is not a type parameter
of the declaration: an unknown name, or a concrete type such as `int`.

## Example

```ofir
fn largest<T>(xs: List<T>) int
where
    U: Ord,
{
    return xs.len()
}

fn main() {
}
```

## Fix

Bound the declaration's own parameter:

```ofir
fn largest<T>(xs: List<T>) int
where
    T: Ord,
{
    return xs.len()
}

fn main() {
}
```
