# E0808: attribute does not apply here

An attribute is placed on a declaration it has no meaning for: `@inline`
or `@test` on a struct, `@cold` on a field, `@align` on a `@packed`
struct, `@repr(C)` on an enum with payloads.

## Example

```ofir
@inline
struct Point {
    x: int
}

fn main() {
}
```

## Fix

Remove the attribute, or move it to a declaration it applies to:

```ofir
struct Point {
    x: int

    @inline
    fn double(self) int {
        return self.x * 2
    }
}

fn main() {
}
```
