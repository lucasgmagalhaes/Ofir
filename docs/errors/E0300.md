# E0300: mismatched types

A value has a different type from the one its place needs: the declared
type of a variable, a parameter, a field or the function's result. Ofir
converts no value implicitly; numbers change type with `as`.

## Example

```ofir
fn half(n: int) int {
    return n / 2
}

fn main() {
    let text: str = half(4)
    println(text)
}
```

## Fix

Give the place the value's type, or convert the value:

```ofir
fn half(n: int) int {
    return n / 2
}

fn main() {
    let n: int = half(4)
    println("{n}")
}
```
