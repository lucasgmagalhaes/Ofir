# E0326: variant named without its enum

A variant is always written with its enum, `Shape.Empty`, even where
the enum is known from the context (ADR 0028). The short form `.Empty`
is not part of the language.

## Example

```ofir
enum Shape {
    Empty
    Circle(int)
}

fn empty() Shape {
    return .Empty
}

fn main() {
    let _s = empty()
}
```

## Fix

```ofir
enum Shape {
    Empty
    Circle(int)
}

fn empty() Shape {
    return Shape.Empty
}

fn main() {
    let _s = empty()
}
```
