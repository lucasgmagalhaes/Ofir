# E0350: the members of a union can be the same type

The members of a union must be distinct in every instantiation (spec
17.1), so a value always says which member it holds. A bare type
parameter can be any type, and two members such as `List<T>` and
`List<int>` are the same type when `T` is `int`.

## Example

```ofir
fn show<T>(value: T | int) {
}

fn main() {
}
```

## Fix

Wrap the parameter in a type of its own, or use an enum:

```ofir
enum Shown<T> {
    Value(T)
    Number(int)
}

fn show<T>(value: Shown<T>) {
}

fn main() {
}
```
