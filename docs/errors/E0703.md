# E0703: use while mutably borrowed

While a mutable borrow of a value is alive, the value can be reached
only through it. Reading the value directly could see it half
changed.

## Example

```ofir
fn main() {
    var list = [1, 2, 3]
    let r = &mut list
    println("{list.len()}")
    r.push(4)
}
```

## Fix

Use the borrow, or end it before the direct use:

```ofir
fn main() {
    var list = [1, 2, 3]
    let r = &mut list
    r.push(4)
    println("{list.len()}")
}
```
