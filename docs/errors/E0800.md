# E0800: constant depends on itself

A constant's value uses the constant itself, directly or through other
constants. Constants are computed at compile time, so a cycle has no
value.

## Example

```ofir
const A = B + 1
const B = A * 2

fn main() {
    println("{A}")
}
```

## Fix

Give one of the constants a value that does not go back to the other:

```ofir
const A = B + 1
const B = 2

fn main() {
    println("{A}")
}
```
