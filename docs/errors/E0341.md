# E0341: no field for this key

An indexed access type `T[K]` names a key that is not a field of `T`
(spec 16.3), or a key type with no keys at all, `keyof ()`.

## Example

```ofir
struct Point {
    x: float
    y: float
}

type Z = Point[.z]

fn main() {
}
```

## Fix

Use the name of a field, or an index below the length of a tuple:

```ofir
struct Point {
    x: float
    y: float
}

type X = Point[.x]

fn main() {
}
```
