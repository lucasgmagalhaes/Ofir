# W0001: unused variable

A variable is declared but its value is never read. It is often a
leftover or a typo for another name. A name that starts with `_` marks
a variable unused on purpose, and `@allow(unused)` silences the warning
for a declaration.

## Example

```ofir
fn main() {
    const count = 5
    println("done")
}
```

## Fix

Use the variable, remove it, or start its name with `_`:

```ofir
fn main() {
    const _count = 5
    println("done")
}
```
