# E0201: defined more than once

Two declarations give the same name in the same scope: two items of a
module, two parameters of a function, two bindings of one pattern, two
variables of one block, or the same field twice in a struct literal.

## Example

```ofir
fn area(w: int, w: int) int {
    return w * w
}

fn main() {
    println("{area(2, 3)}")
}
```

## Fix

Give each one its own name:

```ofir
fn area(w: int, h: int) int {
    return w * h
}

fn main() {
    println("{area(2, 3)}")
}
```
