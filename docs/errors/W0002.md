# W0002: unused import

A module is imported but none of its names is used. Removing the import
keeps the module's dependencies honest.

## Example

```text
// main.of
import shapes           // warning[W0002]: unused import `shapes`

fn main() {
    println("hello")
}
```

## Fix

Remove the import, or use the module:

```text
// main.of
fn main() {
    println("hello")
}
```
