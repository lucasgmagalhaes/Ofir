# E0301: no method on type

A method is called on a value whose type has no method of that name:
neither the type itself nor an interface it implements declares it.

## Example

```ofir
fn main() {
    let name = "ana"
    println("{name.size()}")
}
```

## Fix

Call a method the type has; the methods of `str` are in `std` and its docs:

```ofir
fn main() {
    let name = "ana"
    println("{name.len()}")
}
```
