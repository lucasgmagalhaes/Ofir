# E0353: the branches have different types

A union is never inferred from values (spec 17.3). When the branches of an
`if` or the arms of a `match` have different types and no type is
expected, the compiler does not guess a union.

## Example

```ofir
fn main() {
    let value = if true { 1 } else { "one" }
}
```

## Fix

Write the union type expected; each branch widens to it:

```ofir
fn main() {
    let value: int | str = if true { 1 } else { "one" }
}
```
