# E0701: mutable borrow of a shared borrow

A value is borrowed as mutable while it is also borrowed as shared:
the shared borrower expects it not to change. Passing one variable as
both a `mut` and a plain parameter of a call is the usual case.

## Example

```ofir
fn append(dst: mut List<int>, src: List<int>) {
    for x in src {
        dst.push(x)
    }
}

fn main() {
    var xs = [1]
    append(xs, xs)
    println("{xs.len()}")
}
```

## Fix

Pass a copy as the shared argument:

```ofir
fn append(dst: mut List<int>, src: List<int>) {
    for x in src {
        dst.push(x)
    }
}

fn main() {
    var xs = [1]
    let snapshot = xs.clone()
    append(xs, snapshot)
    println("{xs.len()}")
}
```
