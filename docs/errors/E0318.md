# E0318: recursive type without indirection

A struct or enum contains itself by value, directly or through other
types: its size would be infinite. Put the recursive part behind a
pointer, as `Box<T>`, `Option<Box<T>>` or a collection.

## Example

```ofir
struct Node {
    value: int
    next: Node
}

fn main() {
}
```

## Fix

```ofir
struct Node {
    value: int
    next: Option<Box<Node>>
}

fn main() {
    const n = Node{value: 1, next: Option.None}
    println("{n.value}")
}
```
