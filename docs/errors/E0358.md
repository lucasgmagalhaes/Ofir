# E0358: parameter without default after a default

Arguments are matched to parameters by position, so a parameter with a
default can be left out only at the end. Every parameter after one
with a default needs a default too (spec 3.3).

## Example

```ofir
fn gap(a: int = 1, b: int) int {
    return a + b
}

fn main() {
    println("{gap(1, 2)}")
}
```

## Fix

Move the parameters with defaults to the end:

```ofir
fn gap(b: int, a: int = 1) int {
    return a + b
}

fn main() {
    println("{gap(2)}")
}
```
