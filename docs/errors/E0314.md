# E0314: value cannot be interpolated

`{x}` in a string writes `x` with its `Display`, and `{x:?}` with its
`Debug`. A value whose type has neither, such as `()` or a struct that
implements no `Display`, cannot be written.

## Example

```ofir
struct Point {
    x: int
    y: int
}

fn main() {
    const p = Point{x: 1, y: 2}
    println("{p}")
}
```

## Fix

Write its fields, or derive `Debug` and use `{p:?}`:

```ofir
struct Point {
    x: int
    y: int
}

fn main() {
    const p = Point{x: 1, y: 2}
    println("({p.x}, {p.y})")
}
```
