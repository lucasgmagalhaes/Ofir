# E0323: no enclosing loop has this label

`break name` or `continue name` names a label, but no loop around it has
that label. A label is visible only inside its own loop.

## Example

```ofir
fn main() {
    rows: for i in 0..3 {
        println("{i}")
    }
    for j in 0..3 {
        if j == 1 {
            break rows
        }
    }
}
```

## Fix

Label the loop the jump leaves, or jump to a loop that encloses it:

```ofir
fn main() {
    rows: for i in 0..3 {
        println("{i}")
    }
    cols: for j in 0..3 {
        if j == 1 {
            break cols
        }
    }
}
```
