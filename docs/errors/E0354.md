# E0354: type test that never matches

A type switch arm `p: T => ...` tests whether a `dyn I` value holds a
`T`. If `T` does not satisfy `I`, no `dyn I` value can hold one, and
the arm can never match.

## Example

```ofir
interface Shape {
    fn area(self) int
}

struct Point {
    x: int
}

fn xOf(s: &dyn Shape) int {
    return match s {
        p: Point => p.x
        _ => 0
    }
}

fn main() {
}
```

## Fix

Test for a type that satisfies the interface:

```ofir
interface Shape {
    fn area(self) int
}

struct Square {
    side: int

    fn area(self) int {
        return self.side * self.side
    }
}

fn sideOf(s: &dyn Shape) int {
    return match s {
        q: Square => q.side
        _ => 0
    }
}

fn main() {
}
```
