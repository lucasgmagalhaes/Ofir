# E0004: invalid escape sequence

A backslash in a string or byte literal must start one of the escapes of
the language: `\n`, `\r`, `\t`, `\0`, `\\`, `\"`, `\'`, `\{`, `\}`, `\xHH`
or `\u{H...}`. Any other character after the backslash is an error.

## Example

```ofir
fn main() {
    println("C:\files")
}
```

## Fix

Double the backslash to write one, or use a raw string:

```ofir
fn main() {
    println("C:\\files")
}
```
