# E0309: `break` or `continue` outside a loop

`break` and `continue` act on the innermost `for` or `while` loop. Out
of a loop, there is nothing for them to leave: use `return` to leave
the function.

## Example

```ofir
fn check(n: int) {
    if n < 0 {
        break
    }
    println("{n}")
}

fn main() {
    check(1)
}
```

## Fix

```ofir
fn check(n: int) {
    if n < 0 {
        return
    }
    println("{n}")
}

fn main() {
    check(1)
}
```
