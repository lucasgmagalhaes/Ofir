# E0330: cannot infer type parameter

A generic function or type is used and nothing fixes one of its type
parameters: no argument, expected type or later use says what it is.
`[]` with no element type is the same case.

## Example

```ofir
fn main() {
    let names = []
    println("{names.len()}")
}
```

## Fix

Write the type, or the type arguments, as in `f<int>(x)`:

```ofir
fn main() {
    let names: List<str> = []
    println("{names.len()}")
}
```
