# E0302: wrong number of arguments

A call gives more or fewer arguments than the function has parameters
without a default. The same code is used when a pattern has a different
number of fields from the tuple or variant it matches.

## Example

```ofir
fn add(a: int, b: int) int {
    return a + b
}

fn main() {
    println("{add(1)}")
}
```

## Fix

```ofir
fn add(a: int, b: int) int {
    return a + b
}

fn main() {
    println("{add(1, 2)}")
}
```
