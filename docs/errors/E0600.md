# E0600: use of moved value

A value that is not `Copy` has one owner. Passing it to a function,
assigning it to another variable or returning it moves it: the old name
no longer holds a value, and using it again is an error. This keeps two
owners from freeing the same memory. A `move` parameter takes its
argument this way.

## Example

```ofir
fn consume(s: move str) {
    println(s)
}

fn main() {
    const s = "hello".toOwned()
    consume(s)
    println(s)
}
```

## Fix

Clone the value where it is moved when both copies are needed, or drop
`move` from the parameter when the callee only reads it:

```ofir
fn consume(s: move str) {
    println(s)
}

fn main() {
    const s = "hello".toOwned()
    consume(s.clone())
    println(s)
}
```
