# E0002: unterminated string literal

A string literal started with `"` and the line ended before the closing
`"`. A single-line string cannot span lines: use `\n` for a line break,
or a multi-line string (`"""`).

## Example

```ofir
fn main() {
    println("hello)
}
```

## Fix

```ofir
fn main() {
    println("hello")
}
```
