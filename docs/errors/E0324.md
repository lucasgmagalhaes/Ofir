# E0324: label already used by an enclosing loop

A loop has the same label as a loop around it, so `break name` could not
tell which one it leaves.

## Example

```ofir
fn main() {
    outer: for i in 0..3 {
        outer: for j in 0..3 {
            if i + j == 3 {
                break outer
            }
        }
    }
}
```

## Fix

Give each nested loop its own label:

```ofir
fn main() {
    outer: for i in 0..3 {
        inner: for j in 0..3 {
            if i + j == 3 {
                break outer
            }
        }
    }
}
```
