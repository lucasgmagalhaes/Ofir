# E0802: constant cannot be computed

Computing a constant overflows its type, divides by zero, shifts by
more bits than the type has, or casts a value its target type cannot
hold. At run time the same operation would stop the program, so the
compiler rejects it in a constant.

## Example

```ofir
const SMALL: i8 = 100
const BIG: i8 = SMALL + 100

fn main() {
    println("{BIG}")
}
```

## Fix

Use a type that holds the value, or change the value:

```ofir
const SMALL: i16 = 100
const BIG: i16 = SMALL + 100

fn main() {
    println("{BIG}")
}
```
