# E0332: bound not satisfied

A type argument does not satisfy a bound of its type parameter: the
function or type requires `T: Named`, and the type given does not have
the methods of `Named`.

## Example

```ofir
interface Named {
    fn name(self) str
}

struct Point {
    x: int
}

fn greet<T: Named>(t: T) {
    println("hello, {t.name()}")
}

fn main() {
    greet(Point{x: 1})
}
```

## Fix

Give the type the methods the bound needs, or pass a type that has them:

```ofir
interface Named {
    fn name(self) str
}

struct Point {
    x: int

    fn name(self) str {
        return "point"
    }
}

fn greet<T: Named>(t: T) {
    println("hello, {t.name()}")
}

fn main() {
    greet(Point{x: 1})
}
```
