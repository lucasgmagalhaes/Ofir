# E0336: closure parameter type unknown

A closure parameter without a type gets it from the place the closure
is passed to. A closure stored in a plain `let` has no such place.

## Example

```ofir
fn main() {
    let double = x => x * 2
    println("{double(2)}")
}
```

## Fix

```ofir
fn main() {
    let double = (x: int) => x * 2
    println("{double(2)}")
}
```
