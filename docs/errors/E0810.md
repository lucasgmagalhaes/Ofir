# E0810: attribute written twice

The same attribute appears twice on one declaration. Writing it once has
the same effect, and two differing copies would be ambiguous.

## Example

```ofir
@cold
@cold
fn fail() {
}

fn main() {
    fail()
}
```

## Fix

Write it once:

```ofir
@cold
fn fail() {
}

fn main() {
    fail()
}
```
