# E0811: field type not allowed in a `@packed` struct

A `@packed` struct lays its fields out with no padding, so a field may
be at any address. Only `bool`, numbers and other `@packed` structs can
be read and written there; a type that holds pointers, as `str` or
`List<T>`, cannot.

## Example

```ofir
@packed
struct Header {
    tag: u8
    name: str
}

fn main() {
}
```

## Fix

Keep the packed fields plain, and hold the rest in an ordinary struct:

```ofir
@packed
struct Header {
    tag: u8
    size: u32
}

struct Message {
    header: Header
    name: str
}

fn main() {
}
```
