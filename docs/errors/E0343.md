# E0343: a key must be known at compile time

A parameter of a key type has no runtime value: each call is instantiated
for its key, so the argument must be a key literal, as `.x`, or a key
parameter of the caller (spec 16.2). A local of a key type is not known
while compiling.

## Example

```ofir
struct Point {
    x: float
    y: float
}

fn get<T, K: keyof T>(value: &T, key: K) &T[K] {
    return &value[key]
}

fn main() {
    const p = Point{x: 1.0, y: 2.0}
    const k: .x = .x
    const _ = get(&p, k)
}
```

## Fix

Pass the key literal:

```ofir
struct Point {
    x: float
    y: float
}

fn get<T, K: keyof T>(value: &T, key: K) &T[K] {
    return &value[key]
}

fn main() {
    const p = Point{x: 1.0, y: 2.0}
    const _ = get(&p, .x)
}
```
