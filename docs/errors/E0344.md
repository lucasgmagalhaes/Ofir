# E0344: the condition of a conditional type is not decided

A conditional type `if A is B { X } else { Y }` picks its branch for each
instance, after its arguments are substituted (spec 16.5). Its condition
must then be decided: `A` cannot be a type parameter, and a condition
other than `A is B` must be the type `true` or `false`.

## Example

```ofir
type Odd<T> = if T { int } else { str }

fn main() {
    const x: Odd<int> = 1
}
```

## Fix

Test the type with `is`:

```ofir
type Odd<T> = if T is int { int } else { str }

fn main() {
    const x: Odd<int> = 1
}
```
