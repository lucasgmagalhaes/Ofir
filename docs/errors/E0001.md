# E0001: unexpected character

The lexer found a character that starts no token: it is not part of a
name, a number, a string, an operator or a comment. Characters outside
those are allowed only inside strings and comments.

## Example

```ofir
fn main() {
    let price = 3 $ 2
    println("{price}")
}
```

## Fix

Remove the character, or put it inside a string:

```ofir
fn main() {
    let price = 3 * 2
    println("${price}")
}
```
