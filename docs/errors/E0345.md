# E0345: `infer` outside the pattern of a conditional type

`infer U` names a part of the type matched by the pattern of a
conditional type, `if A is B { X } else { Y }`, and can be used in `X`
(spec 16.5). It has no meaning anywhere else.

## Example

```ofir
type Inner = Option<infer U>

fn main() {
    let x: Inner = Option.None
}
```

## Fix

Match the type with a conditional type:

```ofir
type Unwrap<T> = if T is Option<infer U> { U } else { T }

fn main() {
    let x: Unwrap<Option<int>> = 1
}
```
