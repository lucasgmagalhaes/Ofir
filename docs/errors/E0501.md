# E0501: refutable pattern in `let`

A `let` pattern must match every value of its type, since there is no
other branch to take. A pattern that can fail, such as one variant of
an enum, needs `match`, `if let` or `let ... else`.

## Example

```ofir
enum Shape {
    Circle(int)
    Square(int)
}

fn radius(s: move Shape) int {
    let Shape.Circle(r) = s
    return r
}

fn main() {
    println("{radius(Shape.Circle(2))}")
}
```

## Fix

```ofir
enum Shape {
    Circle(int)
    Square(int)
}

fn radius(s: move Shape) int {
    let Shape.Circle(r) = s else {
        return 0
    }
    return r
}

fn main() {
    println("{radius(Shape.Circle(2))}")
}
```
