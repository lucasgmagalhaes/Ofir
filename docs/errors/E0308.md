# E0308: missing field or argument

A struct literal leaves out a field that has no default, or a call
leaves out a parameter that has no default.

## Example

```ofir
struct Point {
    x: int
    y: int
}

fn main() {
    const p = Point{y: 1}
    println("{p.y}")
}
```

## Fix

Give every field, or declare a default for it (`x: int = 0`):

```ofir
struct Point {
    x: int
    y: int
}

fn main() {
    const p = Point{x: 0, y: 1}
    println("{p.y}")
}
```
