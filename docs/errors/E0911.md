# E0911: dependency not found

A dependency of `ofir.json` cannot be found or fetched: its `path` is not
a directory, its `git` repository cannot be cloned (the note gives what
git reported), the directory has no `ofir.json`, the project there is not
a library (`"build": {"kind": "lib"}`), or its `build.root` file (by
default `src/index.of`) does not exist.

## Example

```jsonc
{
  "name": "app",
  "dependencies": {
    "json": {"path": "../jsno"}
  }
}
```

## Fix

Point `path` at the directory of the library's `ofir.json`, relative to
the manifest that declares it:

```jsonc
{
  "name": "app",
  "dependencies": {
    "json": {"path": "../json"}
  }
}
```
