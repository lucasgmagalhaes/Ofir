# E0805: reserved to the standard library

An `@lang` declaration or an `extern "intrinsic"` block appears outside
the standard library, or an `@lang` names something that is not a
primitive or std type, or names it twice. These declarations tell the
compiler how its built-in types are laid out and which operations it
generates itself, so only std may write them.

## Example

```ofir
@lang("int")
struct MyInt {
}

fn main() {
}
```

## Fix

Declare an ordinary type:

```ofir
struct MyInt {
    value: int
}

fn main() {
}
```
