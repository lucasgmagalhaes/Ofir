# E0809: invalid attribute arguments

An attribute's arguments do not have the form it takes: a missing or
extra argument, a value of the wrong kind, or one out of range, such as
an `@align` that is not a power of two.

## Example

```ofir
@align(3)
struct Block {
    data: int
}

fn main() {
}
```

## Fix

Write the arguments the attribute takes:

```ofir
@align(8)
struct Block {
    data: int
}

fn main() {
}
```
