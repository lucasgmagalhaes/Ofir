# E0803: operation requires `unsafe`

Calling an `unsafe` or `extern` function, dereferencing, offsetting or
converting a raw pointer may break memory safety, so it is allowed only
in an `unsafe` block or an `unsafe fn`. The `unsafe` marks the code the
programmer, not the compiler, vouches for.

## Example

```ofir
unsafe fn risky() int {
    return 1
}

fn main() {
    const n = risky()
    println("{n}")
}
```

## Fix

Wrap the operation in an `unsafe` block, after checking what it needs:

```ofir
unsafe fn risky() int {
    return 1
}

fn main() {
    const n = unsafe {
        risky()
    }
    println("{n}")
}
```
