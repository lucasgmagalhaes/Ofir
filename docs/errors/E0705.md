# E0705: move while borrowed

A value is moved while a borrow of it is alive: the new owner could
drop it, leaving the borrower pointing at freed memory.

## Example

```ofir
fn consume(xs: move List<int>) {
}

fn main() {
    const list = [1, 2, 3]
    const r = &list
    consume(list)
    println("{r.len()}")
}
```

## Fix

Move it after the last use of the borrow:

```ofir
fn consume(xs: move List<int>) {
}

fn main() {
    const list = [1, 2, 3]
    const r = &list
    println("{r.len()}")
    consume(list)
}
```
