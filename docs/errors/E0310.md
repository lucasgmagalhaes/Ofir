# E0310: type used as a value

A type is used where a value is needed, or a value where a type is
needed. A struct is built with a literal, `Name{field: value}`, not
called as a function.

## Example

```ofir
struct Named {
    name: str
}

fn main() {
    let n = Named("x")
    println(n.name)
}
```

## Fix

```ofir
struct Named {
    name: str
}

fn main() {
    let n = Named{name: "x"}
    println(n.name)
}
```
