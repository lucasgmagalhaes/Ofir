# E0204: cannot find module

An `import` names a module that is not in the project, its dependencies
or the standard library. A module `a.b` is the file `a/b.of` under the
project's source directory.

## Example

```ofir
import std.strngs

fn main() {
    println("hello")
}
```

## Fix

Correct the path, or create the module's file:

```ofir
import std.strings

fn main() {
    println("hello")
}
```
