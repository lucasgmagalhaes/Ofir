# E0315: value cannot be modified

A field, element or method that needs `mut self` is changed through a
binding declared with `let`, or through a parameter that is not `mut`.
Only a `var` binding, or a `mut` parameter, can be modified.

## Example

```ofir
struct Point {
    x: int
}

fn main() {
    let p = Point{x: 1}
    p.x = 2
    println("{p.x}")
}
```

## Fix

```ofir
struct Point {
    x: int
}

fn main() {
    var p = Point{x: 1}
    p.x = 2
    println("{p.x}")
}
```
