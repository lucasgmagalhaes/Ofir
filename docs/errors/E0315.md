# E0315: value cannot be modified

A value is changed (a field or element assigned, or a `mut self` method
called) through a binding declared with `let`, or a parameter that is
not `mut`.
Only a `var` binding, or a `mut` parameter, can be modified.

## Example

```ofir
struct Point {
    x: int
}

fn main() {
    let p = Point{x: 1}
    p.x = 2
    println("{p.x}")
}
```

## Fix

```ofir
struct Point {
    x: int
}

fn main() {
    var p = Point{x: 1}
    p.x = 2
    println("{p.x}")
}
```
