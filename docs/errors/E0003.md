# E0003: unterminated block comment

A block comment started with `/*` and the file ended before its `*/`.
Block comments do not nest: the first `*/` closes the comment.

## Example

```ofir
fn main() {
    /* the old version:
    println("a")
    println("b")
}
```

## Fix

```ofir
fn main() {
    /* the old version:
    println("a") */
    println("b")
}
```
