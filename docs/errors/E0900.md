# E0900: cannot read source file

The compiler could not read a source file: the path does not exist, it
names a directory, or the file cannot be opened. The error names the
path the compiler tried.

## Example

```text
$ ofir run helo.of
error[E0900]: cannot read `helo.of`
```

## Fix

Check the path and the file's permissions:

```text
$ ofir run hello.of
```
