# E0307: `const ... else` falls through

The `else` block of `const PATTERN = value else { ... }` runs when the
pattern does not match, and the names of the pattern are then not
bound. So the block must leave: end it with `return`, `break`,
`continue` or a call that does not return, such as `panic`.

## Example

```ofir
fn first(xs: List<int>) int {
    const Option.Some(x) = xs.get(0) else {
        println("empty")
    }
    return *x
}

fn main() {
    println("{first([1])}")
}
```

## Fix

```ofir
fn first(xs: List<int>) int {
    const Option.Some(x) = xs.get(0) else {
        return 0
    }
    return *x
}

fn main() {
    println("{first([1])}")
}
```
