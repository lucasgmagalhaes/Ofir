# E0320: no such variant

A variant is named, in an expression or a pattern, that its enum does
not declare.

## Example

```ofir
enum Shape {
    Circle(int)
    Rect(int, int)
}

fn describe(s: Shape) str {
    return match s {
        Shape.Circle(_) => "circle"
        Shape.Square(_) => "square"
    }
}

fn main() {
    println(describe(Shape.Circle(1)))
}
```

## Fix

```ofir
enum Shape {
    Circle(int)
    Rect(int, int)
}

fn describe(s: Shape) str {
    return match s {
        Shape.Circle(_) => "circle"
        Shape.Rect(_, _) => "rect"
    }
}

fn main() {
    println(describe(Shape.Circle(1)))
}
```
