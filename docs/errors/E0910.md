# E0910: invalid `ofir.json`

The manifest is not valid JSONC (JSON with `//` and `/* */` comments and
trailing commas), or one of its properties has the wrong kind: an entry
of `dependencies` that is neither a version nor an object, an object
without `path`, `git` or a version, or a key that is not a valid package
name (an identifier that is not a keyword).

## Example

```jsonc
{
  "name": "app",
  "dependencies": {
    "json": {"from": "../json"}
  }
}
```

## Fix

Give each dependency a `path` (or, later, a `git` URL or a version):

```jsonc
{
  "name": "app",
  "dependencies": {
    "json": {"path": "../json"}
  }
}
```
