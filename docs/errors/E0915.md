# E0915: dependency named like a module

The key of a dependency is the first segment of the imports that reach
it, so it cannot be `std` or the name of a top-level module of the
project (a file `x.of` or a directory `x` next to the root file): the
import `x.y` would mean two things.

## Example

With a file `json.of` in the project:

```jsonc
{
  "name": "app",
  "dependencies": {
    "json": {"path": "../json"}
  }
}
```

## Fix

Rename the dependency; its imports use the new key (`import jsonc.parser`):

```jsonc
{
  "name": "app",
  "dependencies": {
    "jsonc": {"path": "../json"}
  }
}
```
