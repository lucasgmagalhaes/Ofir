# E0202: private item

An item, field or method of another module is used, but it is not
declared `pub`. Items are private to their module by default.

## Example

```text
// lib.of
pub struct Account {
    pub owner: str
    balance: int
}

// main.of
import lib

fn balanceOf(a: lib.Account) int {
    return a.balance        // error[E0202]: `balance` is private to module `lib`
}
```

## Fix

Mark the item `pub` in its module, or add a public function that gives
what is needed:

```text
// lib.of
pub struct Account {
    pub owner: str
    pub balance: int
}
```
