# E0313: invalid operator for type

An operator is applied to a type that does not support it: arithmetic
on a non-number, negation of an unsigned integer, `?` on a value that
is neither an `Option` nor a `Result`, `??` on a non-`Option`.

## Example

```ofir
fn main() {
    let ok = true
    println("{ok + 1}")
}
```

## Fix

```ofir
fn main() {
    let ok = true
    let n = if ok { 1 } else { 0 }
    println("{n + 1}")
}
```
