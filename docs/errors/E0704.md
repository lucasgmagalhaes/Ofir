# E0704: assignment while borrowed

A variable is assigned while a borrow of it is alive: the old value
would be dropped under the borrower.

## Example

```ofir
fn main() {
    let list = [1, 2, 3]
    const r = &list
    list = [4]
    println("{r.len()}")
}
```

## Fix

Assign after the last use of the borrow:

```ofir
fn main() {
    let list = [1, 2, 3]
    const r = &list
    println("{r.len()}")
    list = [4]
    println("{list.len()}")
}
```
