# E0702: borrow stored or returned

A reference, or a borrowed function value (`fn(...)`), points into
something its holder does not own, so it cannot outlive the call it
was made in: it cannot be stored in a struct field, an enum variant or
a container, or returned. A `move fn` owns what it captures and can be
stored.

## Example

```ofir
struct Button {
    onClick: fn(int)
}

fn main() {
}
```

## Fix

```ofir
struct Button {
    onClick: move fn(int)
}

fn main() {
}
```
