# E0312: integer literal out of range

An integer literal does not fit in the type its place gives it: `256`
is not a `u8`, `-129` is not an `i8`.

## Example

```ofir
fn main() {
    const level: u8 = 300
    println("{level}")
}
```

## Fix

Use a wider type, or a value in range:

```ofir
fn main() {
    const level: u16 = 300
    println("{level}")
}
```
