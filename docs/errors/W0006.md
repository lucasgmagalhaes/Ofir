# W0006: use of deprecated item

A declaration marked `@deprecated` is used. Its author plans to remove
it; the message gives the replacement when the attribute names one.
Uses inside another deprecated declaration, or under
`@allow(deprecated)`, are not reported.

## Example

```ofir
@deprecated("use `parse`")
fn atoi(s: str) int {
    return s.len()
}

fn parse(s: str) int {
    return s.len()
}

fn main() {
    println("{atoi("12")}")
}
```

## Fix

Use the replacement:

```ofir
@deprecated("use `parse`")
fn atoi(s: str) int {
    return s.len()
}

fn parse(s: str) int {
    return s.len()
}

fn main() {
    println("{parse("12")}")
}
```
