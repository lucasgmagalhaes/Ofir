# E0500: non-exhaustive `match`

A `match` must handle every value of its subject. The message names a
pattern that no arm covers; nested enums count, so `Result.Err(e)` must
cover every variant of `e`'s type.

## Example

```ofir
enum Light {
    Red
    Yellow
    Green
}

fn wait(l: Light) int {
    return match l {
        Light.Red => 30
        Light.Green => 0
    }
}

fn main() {
    println("{wait(Light.Red)}")
}
```

## Fix

Add an arm for the missing case, or a `_` arm:

```ofir
enum Light {
    Red
    Yellow
    Green
}

fn wait(l: Light) int {
    return match l {
        Light.Red => 30
        Light.Yellow => 5
        Light.Green => 0
    }
}

fn main() {
    println("{wait(Light.Red)}")
}
```
