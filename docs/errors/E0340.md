# E0340: a key type operator needs another type

`keyof T` needs a struct or tuple type `T`, and the key operators `&` and
`-` need key types on both sides (spec 16.1). An indexed access type
`T[K]` needs a struct or tuple `T` and a key type `K` (spec 16.3).

## Example

```ofir
type Keys = keyof int

fn main() {
}
```

## Fix

Apply `keyof` to a struct or a tuple:

```ofir
struct Point {
    x: float
    y: float
}

type Keys = keyof Point

fn main() {
}
```
