# E0706: borrowed value does not live long enough

A reference to a variable is kept after the block that declares the
variable ends: the variable is dropped there, and the reference would
point at freed memory.

## Example

```ofir
fn main() {
    const a = [1]
    let r = &a
    {
        const b = [2, 3]
        r = &b
    }
    println("{r.len()}")
}
```

## Fix

Declare the value in the outer block, so it lives as long as the reference:

```ofir
fn main() {
    const a = [1]
    const b = [2, 3]
    let r = &a
    {
        r = &b
    }
    println("{r.len()}")
}
```
