# E0331: instantiation nests too deep

A generic function is compiled once for each list of type arguments it
is used with. When it calls itself with a larger type each time, as
`T`, then `Wrap<T>`, then `Wrap<Wrap<T>>`, the copies never end; the
compiler stops at 64 levels.

## Example

```ofir
struct Wrap<T>(T)

fn grow<T>(n: int, x: move T) int {
    if n == 0 {
        return 0
    }
    return grow(n - 1, Wrap(x))
}

fn main() {
    println("{grow(3, 1)}")
}
```

## Fix

Keep the type of the recursive call the same, or use a non-generic helper:

```ofir
fn grow<T>(n: int, x: move T) int {
    if n == 0 {
        return 0
    }
    return grow(n - 1, x)
}

fn main() {
    println("{grow(3, 1)}")
}
```
