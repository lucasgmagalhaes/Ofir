# E0700: two mutable borrows

A value can be borrowed as mutable (`mut` parameter, `&mut`) by only
one borrower at a time: two mutable borrows of the same value could
change it under each other. Passing one variable to two `mut`
parameters of a call is the usual case.

## Example

```ofir
fn grow(a: mut List<int>, b: mut List<int>) {
    a.push(b.len())
    b.push(1)
}

fn main() {
    let xs = [1]
    grow(xs, xs)
    println("{xs.len()}")
}
```

## Fix

Use two values, or a function that takes the value once:

```ofir
fn grow(a: mut List<int>, b: mut List<int>) {
    a.push(b.len())
    b.push(1)
}

fn main() {
    let xs = [1]
    let ys = [2]
    grow(xs, ys)
    println("{xs.len()}")
}
```
