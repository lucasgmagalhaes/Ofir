# E0804: type cannot cross the C boundary

A function declared in or exported to C (`extern "C"`) uses a type
that has no C layout, such as `str`, `List<T>` or a struct without
`@repr(C)`, or is generic: C has one copy of each function and knows
only its own types.

## Example

```ofir
extern "C" {
    fn puts(s: str) i32
}

fn main() {
}
```

## Fix

Use a type with a C layout, such as a raw pointer to bytes:

```ofir
extern "C" {
    fn puts(s: *u8) i32
}

fn main() {
}
```
