# E0356: interface used as a type

An interface names a set of types, not one type. Only a parameter can
name it alone, as shorthand for a type parameter (`fn f(s: Shape)`);
elsewhere write `dyn I` for a value of any type that satisfies it, or
a type parameter.

## Example

```ofir
interface Shape {
    fn area(self) int
}

struct Holder {
    s: Shape
}

fn main() {
}
```

## Fix

```ofir
interface Shape {
    fn area(self) int
}

struct Holder<S: Shape> {
    s: S
}

fn main() {
}
```
