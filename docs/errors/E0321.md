# E0321: operation needs a Copy type

An operation copies a value without calling `clone`: `[value; count]`
repeats one value `count` times. It needs a Copy type; other values are
built one by one.

## Example

```ofir
fn main() {
    const names = ["?"; 3]
    println("{names.len()}")
}
```

## Fix

Build the list one element at a time:

```ofir
fn main() {
    let names: List<str> = []
    for _ in 0..3 {
        names.push("?")
    }
    println("{names.len()}")
}
```
