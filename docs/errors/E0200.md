# E0200: cannot find name

A name is used where nothing of that name is visible: no local
variable, parameter, item of the module or imported name. Names are
visible from their declaration to the end of their block; items of
another module need an `import`.

## Example

```ofir
fn main() {
    let count = 1
    println("{total}")
}
```

## Fix

Use a name that is in scope, or declare the missing one:

```ofir
fn main() {
    let count = 1
    let total = count + 1
    println("{total}")
}
```
