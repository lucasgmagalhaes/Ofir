# E0333: not an interface

A name used as a bound, embedded in an interface or asserted by a type
(`struct C: I`) must be an interface, or one of `Eq`, `Ord`, `Hash` and
`Clone`. A struct or enum cannot be used there.

## Example

```ofir
struct Point {
    x: int
}

fn show<T: Point>(t: T) {
}

fn main() {
}
```

## Fix

```ofir
interface Named {
    fn name(self) str
}

fn show<T: Named>(t: T) {
    println(t.name())
}

fn main() {
}
```
