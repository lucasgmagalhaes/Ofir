# E0316: no field on type

A field is read from a value whose type has no field of that name, or
a tuple is indexed past its last element.

## Example

```ofir
struct User {
    name: str
}

fn main() {
    const u = User{name: "ana"}
    println(u.nmae)
}
```

## Fix

```ofir
struct User {
    name: str
}

fn main() {
    const u = User{name: "ana"}
    println(u.name)
}
```
