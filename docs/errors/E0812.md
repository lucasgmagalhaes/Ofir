# E0812: borrow of a `@packed` field

A field of a `@packed` struct may not be at an address aligned for its
type, and a reference must be aligned. So a field cannot be borrowed
with `&`, nor passed to a `mut` parameter; it can only be read or
assigned by value.

## Example

```ofir
@packed
struct Header {
    tag: u8
    size: u32
}

fn grow(n: mut u32) {
    n = n + 1
}

fn main() {
    var h = Header{tag: 1, size: 2}
    grow(h.size)
    println("{h.size}")
}
```

## Fix

Copy the field into a local, and assign the result back:

```ofir
@packed
struct Header {
    tag: u8
    size: u32
}

fn grow(n: mut u32) {
    n = n + 1
}

fn main() {
    var h = Header{tag: 1, size: 2}
    var size = h.size
    grow(size)
    h.size = size
    println("{h.size}")
}
```
