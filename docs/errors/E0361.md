# E0361: a const parameter is not of type `int`

A const parameter (spec 8.7) holds a compile-time integer: its type is
`int`. Other types are not accepted.

## Example

```ofir
struct Flags<const B: bool> {
    on: int
}
```

## Fix

Declare the parameter as an `int`, or use a type parameter:

```ofir
struct Flags<const B: int> {
    on: int
}

fn main() {
    const _ = Flags<1>{on: 0}
}
```
