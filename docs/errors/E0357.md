# E0357: invalid format specifier

A specifier after `:` in an interpolation (spec 1.7) is malformed, or
does not apply to the value's type: a precision (`.2`) is for floats,
`x` and `b` are for integers, zero padding is for numbers.

## Example

```ofir
fn main() {
    let n = 42
    println("{n:.2}")
}
```

## Fix

```ofir
fn main() {
    let n = 42
    println("{n:05}")
}
```
