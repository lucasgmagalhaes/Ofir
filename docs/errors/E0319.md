# E0319: invalid enum discriminant

An explicit discriminant (`A = 1`) is allowed only in an enum whose
variants carry no payload, and two variants cannot have the same one.

## Example

```ofir
enum Status {
    Ok = 0
    Failed = 0
}

fn main() {
}
```

## Fix

```ofir
enum Status {
    Ok = 0
    Failed = 1
}

fn main() {
}
```
