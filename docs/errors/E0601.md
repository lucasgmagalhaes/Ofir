# E0601: possibly uninitialized variable

A variable declared without a value is read on a path where nothing
was assigned to it: every path from the declaration to the use must
assign it first.

## Example

```ofir
fn pick(flag: bool) int {
    let n: int
    if flag {
        n = 1
    }
    return n
}

fn main() {
    println("{pick(true)}")
}
```

## Fix

Assign it on every path, or give it a value where it is declared:

```ofir
fn pick(flag: bool) int {
    let n: int
    if flag {
        n = 1
    } else {
        n = 0
    }
    return n
}

fn main() {
    println("{pick(true)}")
}
```
