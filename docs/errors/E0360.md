# E0360: the closure captures a value that is not `Send` or `Sync`

A closure converted to a `+ Send` function type, such as the one
`task.run` takes, may run on another task (spec 14.3). A `move` closure
moves its captures there, so each must be `Send`; a borrowing closure
shares them, so each must be `Sync`. Raw pointers are neither, so a struct
that holds one is neither unless it is marked `@threadsafe`.

## Example

```ofir
import std.task

struct Handle {
    p: *int,
}

unsafe fn open() Handle {
    return Handle{p: 0 as *int}
}

fn main() {
    let h = unsafe { open() }
    let t = task.run(move () => {
        let _ = h
    })
    t.join()
}
```

## Fix

Move only `Send` values to the task, such as the data the pointer reaches:

```ofir
import std.task

fn main() {
    let data = [1, 2, 3]
    let t = task.run(move () int => data.len())
    println("{t.join()}")
}
```
