# E0813: C symbol defined twice

Two functions give C the same symbol name, through `@export("name")` or
an `extern "C" fn` of that name. The linker keeps one symbol per name,
so a program defines each once.

## Example

```ofir
@export("twice")
extern "C" fn twiceA(n: i32) i32 {
    return n * 2
}

extern "C" fn twice(n: i32) i32 {
    return n + n
}

fn main() {
}
```

## Fix

Give each function its own symbol:

```ofir
@export("twice")
extern "C" fn twiceA(n: i32) i32 {
    return n * 2
}

extern "C" fn twiceB(n: i32) i32 {
    return n + n
}

fn main() {
}
```
