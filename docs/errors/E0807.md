# E0807: unknown attribute

An attribute name is not one the language defines. Attributes are a
closed set (`@inline`, `@cold`, `@test`, `@deprecated`, `@allow`,
`@repr`, `@packed`, `@align`, `@export`, `@link`, `@cfg`, ...): a
misspelt one is an error, not ignored.

## Example

```ofir
@inlined
fn twice(n: int) int {
    return n * 2
}

fn main() {
    println("{twice(2)}")
}
```

## Fix

Use the attribute's name:

```ofir
@inline
fn twice(n: int) int {
    return n * 2
}

fn main() {
    println("{twice(2)}")
}
```
