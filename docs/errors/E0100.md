# E0100: expected X, found Y

The parser expected one token or construct and found another. The
message names both; the span points at the token found. A missing
closing bracket, a missing `{` or a keyword used as a name are the
usual causes.

## Example

```ofir
fn main() {
    let n = (1 + 2
    println("{n}")
}
```

## Fix

```ofir
fn main() {
    let n = (1 + 2)
    println("{n}")
}
```
