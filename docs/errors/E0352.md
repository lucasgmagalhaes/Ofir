# E0352: type is not a member of the union

A type test pattern `x: T` on a union value narrows it to the member `T`
(spec 17.4). `T` must be a member of the union, or a union whose members
are all members of it; any other type can never match.

## Example

```ofir
struct A {
    n: int
}

struct B {
    n: int
}

struct C {
    n: int
}

fn read(value: A | B) int {
    return match value {
        a: A => a.n
        c: C => c.n
        _ => 0
    }
}

fn main() {
}
```

## Fix

Test only the members of the union:

```ofir
struct A {
    n: int
}

struct B {
    n: int
}

fn read(value: A | B) int {
    return match value {
        a: A => a.n
        b: B => b.n
    }
}

fn main() {
}
```
