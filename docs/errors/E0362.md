# E0362: a type where a constant is expected, or the reverse

A const parameter (spec 8.7) takes an integer literal, a `const` item of
type `int` or a const parameter; a type parameter takes a type. The length
of an array type is an integer constant or a const parameter.

## Example

```ofir
struct Buffer<T, const N: int> {
    items: [T; N]
}

fn main() {
    const _ = Buffer<u8, int>{items: [0; 4]}
}
```

## Fix

Give a constant for `N`:

```ofir
struct Buffer<T, const N: int> {
    items: [T; N]
}

fn main() {
    const _ = Buffer<u8, 4>{items: [0; 4]}
}
```
