# W0004: unreachable code

Code can never run: a statement after a `return`, `break` or
`continue`, or a `match` arm after arms that already match every value.

## Example

```ofir
fn sign(n: int) int {
    return match n > 0 {
        true => 1
        false => -1
        true => 0
    }
}

fn main() {
    println("{sign(2)}")
}
```

## Fix

Remove the unreachable code:

```ofir
fn sign(n: int) int {
    return match n > 0 {
        true => 1
        false => -1
    }
}

fn main() {
    println("{sign(2)}")
}
```
