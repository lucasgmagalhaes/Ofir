# E0006: unescaped `}` in string literal

In a string literal `{` starts an interpolation and `}` ends it. A `}`
outside an interpolation is an error, so a literal brace is written
`\}` (and `\{` for the opening one).

## Example

```ofir
fn main() {
    println("smile :}")
}
```

## Fix

```ofir
fn main() {
    println("smile :\}")
}
```
