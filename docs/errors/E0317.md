# E0317: `copy struct` with a non-Copy field

A `copy struct` is copied bit by bit when it is passed or assigned, so
each field must be a Copy type too: numbers, `bool`, `char` and other
copy structs. A `str` or a `List` owns memory and cannot be copied this
way.

## Example

```ofir
copy struct Label {
    text: str
}

fn main() {
    const l = Label{text: "a"}
    println(l.text)
}
```

## Fix

Make it a plain `struct`, and clone it where a copy is needed:

```ofir
struct Label {
    text: str
}

fn main() {
    const l = Label{text: "a"}
    println(l.text)
}
```
