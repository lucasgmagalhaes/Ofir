# E0306: invalid named argument

A named argument does not match the call: the function has no parameter
of that name, the parameter is given twice, or a positional argument
follows a named one. Named arguments come after the positional ones.

## Example

```ofir
fn connect(host: str, port: int = 80) {
    println("{host}:{port}")
}

fn main() {
    connect("example.org", prot: 8080)
}
```

## Fix

```ofir
fn connect(host: str, port: int = 80) {
    println("{host}:{port}")
}

fn main() {
    connect("example.org", port: 8080)
}
```
