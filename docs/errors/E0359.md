# E0359: invalid default value

A default is evaluated at each call that leaves it out, in the callee's
module. It must be a constant expression, `[]`, or a call to an
associated function without arguments (spec 3.3): it cannot read other
parameters or variables.

## Example

```ofir
fn early(a: int, b: int = a) int {
    return a + b
}

fn main() {
    println("{early(1)}")
}
```

## Fix

Use a constant, or a second function for the other case:

```ofir
const STEP: int = 1

fn early(a: int, b: int = STEP) int {
    return a + b
}

fn main() {
    println("{early(1)}")
}
```
