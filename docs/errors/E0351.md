# E0351: type cannot be a member of a union

A union holds its member as the payload of a variant (spec 17.6), so a
member must be a type a variant can hold: not a reference, an unsized type
(`dyn I`) or `!` (spec 17.1). A union of keys (`.x | .y`, spec 16) holds
only key types; it cannot mix a key type with another type.

## Example

```ofir
struct Point {
    x: int
}

type PointRef = &Point

fn show(value: int | PointRef) {
}

fn main() {
}
```

## Fix

Hold the value itself:

```ofir
struct Point {
    x: int
}

fn show(value: int | Point) {
}

fn main() {
}
```
