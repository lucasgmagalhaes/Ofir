# E0338: interface not usable as `dyn`

A `dyn I` value calls its methods through a table of function
pointers. A method of `I` without a body that takes `self` by value, is
generic or mentions `Self` cannot be in that table, so such an
interface has no `dyn` form.

## Example

```ofir
interface Cloner {
    fn duplicate(self) Self
}

fn useCloner(c: &dyn Cloner) {
}

fn main() {
}
```

## Fix

Use a type parameter instead, which is compiled for each type:

```ofir
interface Cloner {
    fn duplicate(self) Self
}

fn useCloner<C: Cloner>(c: &C) {
}

fn main() {
}
```
