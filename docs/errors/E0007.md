# E0007: malformed multi-line string

A multi-line string opens with `"""` at the end of a line and closes with
`"""` on a line of its own. Its indentation is the closing line's: each
line loses that much leading whitespace. Text after the opening `"""`,
or a line indented less than the closing `"""`, is an error.

## Example

```ofir
fn main() {
    const text = """first
        second
        """
    println(text)
}
```

## Fix

Start the text on the line after the opening `"""`:

```ofir
fn main() {
    const text = """
        first
        second
        """
    println(text)
}
```
