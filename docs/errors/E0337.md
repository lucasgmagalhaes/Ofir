# E0337: assignment to a `move` capture

A `move` closure takes its own copy of each value it captures, and those
copies are immutable: assigning to one would not change the variable
outside, so it is an error.

## Example

```ofir
fn main() {
    var total = 0
    const bump = move () => {
        total += 1
    }
    bump()
    println("{total}")
}
```

## Fix

Capture by reference, without `move`, to change the outer variable:

```ofir
fn main() {
    var total = 0
    const bump = () => {
        total += 1
    }
    bump()
    println("{total}")
}
```
