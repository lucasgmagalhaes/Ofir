# E0303: missing return value

A function that returns a value can reach the end of its body without a
`return`: some path through it, often an `if` without `else`, gives no
value.

## Example

```ofir
fn sign(n: int) int {
    if n < 0 {
        return -1
    }
}

fn main() {
    println("{sign(3)}")
}
```

## Fix

Return a value on every path:

```ofir
fn sign(n: int) int {
    if n < 0 {
        return -1
    }
    return 1
}

fn main() {
    println("{sign(3)}")
}
```
