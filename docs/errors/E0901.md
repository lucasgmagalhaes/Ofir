# E0901: not supported yet

The program uses a part of the language that the specification defines
but this compiler version does not implement yet. The message names the
feature; `docs/roadmap.md` says when it is planned.

## Example

```ofir
interface Source<T> {
    fn next(mut self) Option<T>
}

interface Rewind<T> {
    Source<T>
    fn reset(mut self)
}

fn main() {
}
```

## Fix

Write the methods out until the feature is supported:

```ofir
interface Source<T> {
    fn next(mut self) Option<T>
}

interface Rewind<T> {
    fn next(mut self) Option<T>
    fn reset(mut self)
}

fn main() {
}
```
