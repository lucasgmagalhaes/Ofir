# E0801: constant uses a non-constant

A constant's value is computed by the compiler, so it may use only
literals, other constants and operators. A function call, a variable or
a method call has no value at compile time.

## Example

```ofir
fn limit() int {
    return 10
}

const MAX = limit() * 2

fn main() {
    println("{MAX}")
}
```

## Fix

Write the value with constants, or compute it at run time with `const`:

```ofir
const LIMIT = 10
const MAX = LIMIT * 2

fn main() {
    println("{MAX}")
}
```
